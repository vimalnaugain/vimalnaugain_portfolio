# Vimal Naugain · portfolio

Static portfolio site (plain HTML, no build step).

- `index.html` is the whole site. Pages are hash-routed (`#projects`, `#airtel-billing` …).
- `cs/` … `cs8/` hold the case-study images; `Vimal-Naugain-Resume.pdf` is the resume.
- Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
